# 0010. 토큰 폐기는 블랙리스트 + 회원 단위 폐기 시각

> 상태: ✅ 확정 · 결정일 2026-11-03 · 결정한 사람: 사용자 · 팀
> 대체: - · 대체됨: -

## 배경

로그아웃 · 탈퇴 · 비밀번호 변경 때 이미 발급된 Access 토큰을 막아야 합니다.

## 결정

로그아웃은 `auth:blacklist:{토큰 해시}`(토큰 남은 수명), 탈퇴 · 비밀번호 변경은 `auth:revoked-member:{memberId}` = 끊은 시각(30분, `iat`가 이전이면 거절), 전체 로그아웃은 회원별 Refresh Set으로 일괄 삭제합니다. Gateway가 두 키를 확인합니다.

## 고른 이유

토큰마다 기록하지 않고 회원당 키 하나로 모든 기기를 끊을 수 있고, TTL이 Access 수명과 같아 키가 쌓이지 않습니다.

## 다른 안

| 안 | 버린 이유 |
|---|---|
| Access 만료까지 허용 | 탈퇴 후 30분간 토큰이 살아 있음 |
| 모든 토큰을 Redis에 저장 | 요청마다 조회 · 저장량 증가 |
