# 0006. 시스템 지갑은 payment가 wallet_type으로 소유

> 상태: ✅ 확정 · 결정일 2026-11-03 · 결정한 사람: 김환희 · 팀
> 대체: - · 대체됨: -

## 배경

세미는 홀딩 · 매출 지갑을 시스템 회원 계정으로 만들어 회원 ID를 알아야 했습니다. 서비스를 나누면 그 ID를 어디에 둘지가 문제였습니다.

## 결정

payment가 `WALLET.wallet_type`(`MEMBER` / `HOLDING` / `REVENUE`)으로 시스템 지갑을 직접 소유합니다. 회원 계정 · 복제본 · 환경변수에 시스템 ID를 두지 않습니다.

## 고른 이유

돈의 흐름이 payment 안에서 끝나고, member에 가짜 회원을 만들 필요가 없습니다.

## 다른 안

| 안 | 버린 이유 |
|---|---|
| 시스템 회원 ID를 환경변수로 | 서비스마다 같은 값을 맞춰야 함 |
| 복제본에 시스템 회원 표시 | member 데이터에 의존 |
