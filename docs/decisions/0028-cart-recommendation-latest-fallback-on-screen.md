# 0028. 장바구니 추천이 비면 화면에서 최신 상품으로 대신

> 상태: ✅ 확정 · 결정일 2026-11-18 · 결정한 사람: 담당자 (AI 장바구니 추천 #289)
> 대체: - · 대체됨: -

## 배경

처음 정책은 「추천이 실패하면 최신 상품으로 대신」이었습니다. 11/16 장바구니 추천 확정(#289, PR #472)에서 이 대체를 지우고 「실패 · 타임아웃이면 빈 목록」으로 바꿨는데, 지운 이유는 기록하지 않았습니다. 11/18 웹 시안을 점검하면서 장바구니 「같이 키우기 좋은 식물」 영역이 비어 보이는 경우가 화면 경험상 좋지 않다는 의견이 나왔습니다.

빈 목록이 되는 경우는 ai 장애 · 타임아웃(2초)만이 아닙니다.

- 상품 데이터를 비우고 시작해 판매 중 상품이 적을 때
- ai가 고른 후보가 market에서 본인 상품 · 구매 불가로 모두 걸러질 때
- 장바구니가 비어 있고 최근 구매 확정 상품도 없을 때

## 결정

추천 API(`GET /api/v1/cart/recommendations`)는 지금처럼 실패 · 타임아웃 · 결과 없음이면 빈 목록을 돌려줍니다. 화면은 빈 목록을 받으면 `GET /api/v1/products?onSale=true`(최신순)를 불러 「새로 올라온 식물」로 보여 줍니다. 이때 「AI 추천」 표시와 추천 이유는 붙이지 않습니다. 판매 중 상품이 하나도 없을 때만 영역을 숨깁니다.

## 고른 이유

- ai 밖에서 대신하므로 ai 장애 · 타임아웃 때도 영역이 채워집니다.
- 백엔드 변경 없이 이미 있는 공개 목록 API로 됩니다. 일정(11/20 종료) 안에 끝낼 수 있습니다.
- 대체 상품은 「AI 추천」이 아니라 「새로 올라온 식물」로 따로 표시합니다. 추천 평가(#507)의 「추천이 없는 요청 비율」 · 「요청 개수를 채운 비율」이 대체 상품으로 부풀지 않습니다.

## 다른 안

| 안 | 버린 이유 |
|---|---|
| 빈 목록이면 영역 숨김 (11/16 결정) | 영역이 자주 비어 화면이 허전함 |
| ai 안에서 규칙 기반 대체 (같은 카테고리 · 비슷한 관리 조건) | ai 장애 · 타임아웃 때는 여전히 빈 목록. #294 범위가 늘어남. #507 평가에서 「추천이 없는 요청 비율」이 높게 나오면 그때 다시 검토 |
| market이 최신 상품으로 채움 | market에 최신 상품을 고르는 product 내부 API가 따로 필요함 |
| 같은 판매자의 다른 상품 | 배송비 절약이라는 이유는 좋지만, 그 판매자가 다른 상품을 안 팔면 비어 있음. 추천과 별개 영역으로 둘 수 있음 |
