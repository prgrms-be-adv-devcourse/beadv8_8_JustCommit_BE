# 프로젝트 개요

> 언제 읽나: 처음 레포를 볼 때, 전체 목표 · 범위 · 일정을 확인할 때
> 상태: ✅ 확정 · 마지막 수정 2026-11-10 · 관련: Miro 1~4, 노션 기획안 「1. 프로젝트 개요」

## 목표

| 목표 | 내용 | 완료 기준 |
|---|---|---|
| MSA 전환 | 6개 모듈을 서비스별 배포 · 서비스별 DB로 분리 | 모든 서비스가 독립 실행되고 가입 → 구매 → 배송 → 구매 확정 → 정산이 그대로 통과 |
| 외부 API 호환 | Gateway가 기존 경로로 라우팅 | 프론트 변경 없이 기존 API 동작 (경로 · 응답 형식 동일) |
| 데이터 정합성 | Saga로 보상, Outbox로 이벤트 유실 방지 | 결제 · 환불 · 정산 중 한 서비스가 실패해도 돈 · 주문 상태가 어긋나지 않음 |
| AI 추천 | 장바구니에 담은 품종 기준 "같이 키우기 좋은 식물" | 장바구니 화면에 추천 노출, ai가 죽어도 구매는 정상 |
| 검색 고도화 | OpenSearch 상품 검색 (nori · 정규화 · 오타 허용), 문장으로 찾기는 챗봇 | "몬 스테라" · "몬스테러"로도 몬스테라가 검색됨 |
| 안정성 · 운영 | Gateway 인증, 장애 격리, 바뀐 서비스만 배포, 모니터링 · 추적 ID | 서비스 하나를 내려도 나머지가 동작하고 요청 하나를 여러 서비스 로그에서 추적 |

## 범위

| 포함 | 제외 |
|---|---|
| 서비스 분리 · Gateway · Saga · Outbox · K3s(Gateway · market 2파드, ai) | 신고 · 제재, 쿠폰, 경매 · 가격 제안 |
| 판매자 수락 · 거절, 반품 · 조정 정산, 충전 취소 · 인출 | 찜 (인기순 정렬) |
| 품종 기준 AI 추천 · 챗봇 (⬜ 범위 보류) | 상품 의미 검색 · 사진 검색 · 초성 검색 · 자동완성 |
| OpenSearch 검색 · 사진 검수(OpenAI Moderation · Claude Haiku) · 이의 신청 | 이미지 기반 추천 |
| 지역 구분 배송비 요금표, 리뷰, 판매자 상점 | 날씨 · 계절 배송 제한, 반품 사진 · 판매자 검수 |
| 관측(Loki · Tempo · Prometheus · Grafana), k6 부하 테스트 | 서킷 브레이커, 로그용 ELK |

확장 화면은 **판매자 상점(리뷰 · 판매 상품)**만 합니다. 추천이 실패하면 최신 상품으로 대신합니다.
